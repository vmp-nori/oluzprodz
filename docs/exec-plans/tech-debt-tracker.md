# Technical debt tracker

Policy: Record only concrete debt with impact, evidence, an activation trigger, and a bounded repair; remove resolved entries promptly.

| Item | Impact | Evidence | Trigger | Owner/status |
| --- | --- | --- | --- | --- |
| None recorded | — | — | — | Open |

Maintenance cadence: Run documentation checks when architecture, workflow, or product scope changes; no scheduled maintenance initially.

Recurring checks:

- Broken documentation links
- Stale deferred-item triggers
- Architecture boundary drift
- Unused dependencies and media
- Quality grades unsupported by evidence
