# OluProdz

A desktop-first sports photography and videography portfolio for Oluwasegun Ogunjobi.

## Development

Use Node.js 22 and npm.

```bash
npm install
npm run dev
```

For a checkout-specific development port:

```bash
npm run dev:worktree
```

Run the complete local validation suite with:

```bash
npm run check
```

The application is intended for Vercel, but production deployment requires explicit owner approval.

Repository architecture and workflow guidance begin in [AGENTS.md](AGENTS.md).
